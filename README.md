# 格朗德 · 魔晶回响 3.6

带有分支路线的回合制远征 demo《停机之前》。七名考察队员被困在博洛伦地下；同行者需要恢复通风、查明旧设施故障，打通撤离路线，把人带回来。考察队与七位可用角色是两组不同的人，游墓是游木体内的另一人格，不额外占用队伍位置。

本版有 **10 名 BOSS、7 名可用角色、每人 5 个技能槽、5 套三维战斗场景、35 项成长奖励、362 句配有中文合成音频的剧情对白与旁白**。新远征在两处分岔各选一条路，一周目打八场；间章选择会影响下一战与三种结局。自由挑战支持三人小队和独狼，主界面可查看已解锁角色的图鉴。

3.6 将三名魔力角色区分为 **4 条念线、3 格充能和 10 条记录**，加入耗费 2 AP 的批量准备技能，把回魔统一归入各自被动。少量多次兑现有更高回魔效率，大量兑现有更强效果；准备技能的即时收益较弱，需要安排安全窗口。AP 改为每轮基础供给，加上最多 2 点结余。BOSS 挑战按真实胜利开放，并有独立的 GM 全开开关。详见 [3.6 更新说明](docs/update-3.6.md) 和 [七名角色的玩法指南](docs/角色玩法指南.md)。

3.4 的表现改进继续保留：技能音效按 13 种攻击主题和 6 种目标材质区分；每段真实扣血同步触发声音、生命显示、受击动作与命中特效。新增 11 组场景配乐和 7 类环境粒子，重新安排宽屏与笔记本的战斗布局，战斗手册改为章节导航、角色卡和可展开的敌人条目。详见 [表现更新说明](docs/update-3.4.md)。

## 直接开始

**双击本目录的「开始游戏.html」，使用 Chrome 或 Edge 打开。** 修改源码或资源后，需先运行 `npm run offline` 更新这个独立文件。

从 GitHub 下载时，点击 **Code → Download ZIP**，解压后打开「开始游戏.html」。仓库中的 HTML 源码预览页不能直接运行游戏。

离线构建会内嵌游戏代码、四张美术图集、三维引擎、潜行 GLB 模型、362 段对白 MP3、音乐与音效。生成后可以只复制这一文件，无需安装依赖、登录或联网。浏览器需要支持 WebGL 2；声音需要首次点击授权播放。当前版本的集成验收范围见 [3.6 更新说明](docs/update-3.6.md) 与 [验证报告](docs/test-report.md)。

开发预览地址为 `http://127.0.0.1:4173/`，仅在本机服务运行期间有效。首次游玩可选「初探」熟悉机制；「标准」需要安排应对与恢复，「险境」进一步增加压力。三档保留完整机制。

## 自然解锁与 GM 试玩

标题页底部或暂停菜单中点击 **GM · 试玩开关**。角色全开与 BOSS 全开是两个独立开关，均可再次关闭。角色关闭后恢复实际招募名单；BOSS 关闭后只显示真正打赢过的敌人。开关本身不写入招募或胜利记录，开着 GM 实际打赢的战斗仍会记录胜利。

正常流程中，击败远征 BOSS 后才在标题页出现对应挑战；旧战绩及当前远征的胜利历史会迁移。尚未打赢任何 BOSS 时，从「开始远征」进入故事。自由挑战可自选三人或独狼单人；正在进行的战斗允许打完，之后按正常解锁校正选择，已获成长与剧情进度保留。

**重置游戏进度**是独立入口，需在游戏内确认。它清除本游戏的自由挑战、远征、招募和战绩，关闭GM并恢复三名初始角色，保留声音偏好。旧版GM没有自然招募记录时，会按当前远征的胜利历史恢复并说明。自由挑战使用初始技能及原有数值，不自动发放成长；组队和开关状态都会保存。

每章按 **战前对话 → 战斗 → 战后对话 → 奖励 → 整备** 推进；分支战后增加事件选择，终章战后进入结局。对白可点击任意非交互空白区域推进，也可使用按钮、空格或 Enter。文字选择、镜头拖动及点击控件不会误翻页。支持返回上一句、查看记录、重听、自动播放或跳过，位置自动保存。

前七战各选择一项尚未获得的成长，**35 项投放内容，一次新远征获得其中 7 项**。击败刃卫、司祭、守卫和巨人后依次招募游木、哈特、潜行和补丁Z。整备时可以替换队员和技能；下场补满生命、药剂，并恢复各角色的初始战斗资源。战败可重整本章，已经获得的奖励与同伴保留。角色解锁写入本机图鉴，重新开局仍可查阅和用于独狼挑战；奖励及技能成长属于当前远征。

## 角色与施法资源

只使用四类基础施法资源：**气息、连击、平衡、魔力**。三名魔力角色把魔力转化为念线、充能或记录，再通过消耗触发被动回魔；直感、剑势、标本、接管、护盾等另外作为状态显示。

| 角色 | 资源与基本循环 | 成长方向 |
| --- | --- | --- |
| 尼布斯拉姆 | 气息初始10、每轮回2；射击积累直感，满层强化重型射击或迎击；掩护射击提供队伍护盾 | 三段射击、满直感强化、对标记目标追击 |
| 艾佩莉雅 | 连击初始0；交替物理与魔法强化伤害、削韧和连击获取；战术重整主动准备连击；伊甸之约和地狱哨兵各消耗6点连击 | 交替返还、多段爆发、满足条件时降低AP |
| 雷克老板 | 平衡初始0，范围 **−10至+10，每轮向0回2**。肉身同调强化自身与剑势，剑式偏正；缚足同化削弱敌人，咒弹偏负；领域换向主动切换路线 | 归零、低AP自身同调、物理清账三连 |
| 哈特蒙斯 | 魔力转化为念线；固定逐条安抚换回魔力并削弱敌人，大额兑现提供协同攻击增幅或行动封锁 | 通路接续、护念回响、心智协同、精神截流、破绽提醒 |
| 潜行 | 战甲保留3格充能；单格脉冲高效回收并驱散，两格光束穿透，满载三格自动强化并施加易伤，装甲消费充能保护自身 | 稳固聚焦、协同装甲、灭绝耀光、解除协议、接地回路 |
| 游木／游墓 | 气息初始10，每轮回2；手术刀→切除与创口→移植。血誓主动献血至40%生命，使游墓接管并嘲讽两轮，每场一次 | 精密缝合持续恢复、无菌移植、护住身体、病理标记、术后观察 |
| 补丁Z | 魔力抄录术式；观测侧重攻击与易伤，收录侧重净化、驱散与控制，销毁不同数量记录回魔 | 时之扉、精确计时、厚页书阵、读秒禁令、交叉索引 |

三名魔力角色的魔力上限均为10，魔力和二级资源都不随回合自动回复。哈特的「展开心智领域」用8魔力一次编4条念线；潜行的「反应炉灌注」用9魔力装满3格；补丁的「批量抄录」用8魔力写6条，最多存10条。这三项均花2 AP，只有资源转化，不兼带攻击或保护。

回魔由被动按每次行动结算一次：哈特拆1／2／3／4条，回3／4／5／5魔力；潜行用1／2／3格，回4／5／6魔力；补丁无论一次销毁几条，观测固定回2，收录固定回3。少量多次效率更高，大额兑现效果更强；多段命中不多次回魔，溢出上限的部分会损失。技能悬浮框显示本次实际被动回魔与溢出量。

满库存仍能选择固定小额兑现。二级资源为空且已装配技能没有可支付的转化时，可花1 AP应急提炼，再另花行动点兑现；应急没有原技能的战斗效果。五槽装配若移除哈特或潜行的全部常规转化技，一项必定保留的辅助槽会临时承担备用转化，装满后恢复原招式，避免装配导致永久卡死。

每批护盾分别持续两次敌方回合，先消耗快到期的批次，新护盾不会刷新旧护盾。总上限60；敌人被控或破韧而跳过行动时，护盾仍会到期。

游木只切除镜片、孢压、蓄电、封页或迷雾，不能偷取BOSS阶段、抗控或核心规则。船长接管持续两轮、承伤减少35%，仍可能倒下；炮击可以提前结束。退出后虚脱两轮，输出减少20%、承伤增加20%，仍能治疗与使用药剂。

每人默认有 **5 个可用技能**，魔力角色另有2项可解锁技能，其他角色另有1项；每场始终装配5个。新技能自动放入第5槽（T），可在整备时调整。雷克的强化剑枪、游木的切除／移植与船长技能、补丁Z按观测与收录选择的兑现招式会直接在原技能槽变名，高亮并显示当前效果。

## 战斗操作与信息

- 三人小队每轮获得基础 **6 AP**，独狼基础 **5 AP**。结束回合时最多保留2点剩余AP，所以下轮分别最多8／7点；不能无限积攒。中央资源栏和结束按钮会显示本轮构成与下轮实际点数。三人共用同一池，15个已装配技能同时显示。
- **技能按钮显示物理／魔法／辅助标签和实时削韧值**。悬浮技能查看伤害、段数、资源支付与返还、当前变招和限制；悬浮头像查看整体机制，悬浮BUFF图标查看状态。
- 右侧预告显示敌招、目标与伤害。花1 AP准备招架、回避或迎击，改选免费；已经花掉的应对费用不会作为结余再次保留。留点不延长护盾、冷却、核心或终幕的时限。
- 群体主招的招架减伤30%、回避减伤60%，需要结合护盾、防御、拆层或恢复；迎击承担更多伤害换反击。应对只覆盖主招，不覆盖另行追加的攻击。
- BOSS韧性上限为 **160**。玩家阶段破韧取消敌人当轮行动并提供50%增伤；敌人已出手后由应对造成的破绽在下一玩家回合提供增伤，**敌人仍会出招**。恢复架势后有一整轮抗控。
- 药剂和普通防御各消耗1 AP。每场3瓶药剂，可治疗或救起选中的队员。普通防御只保护该队员。
- **B** 打开十名BOSS的游戏内招式档案；**H** 查看通用规则。拖动战场可水平旋转360°，滚轮缩放，镜头重置按钮恢复适合当前编队的视角。
- 本版保留已有BOSS伤害，不因新增治疗或角色而降低敌人攻击。更多保护手段仍须占用输出、回资源和应对所用的同一组AP。

魔晶巨人的核心须在期限内完成物理、魔法各3次命中，多段逐段计算。最终BOSS耗尽生命后进入停机过载：各命中至少一次物理与魔法，准备任意应对，再结束回合守住最后放电。仅打空生命不会直接获胜；超时会重组。逐招数值以游戏内预告与BOSS档案为准。

独狼改用任意属性的命中次数处理上述两项机制，避免单属性角色无法通关。它是另外配置数值的单场挑战；剧情远征仍从已同行的角色中安排三人。图鉴会完整解释技能费用、效果、被动与成长条件。

| 操作 | 快捷键 |
| --- | --- |
| 选择队员 | 1 / 2 / 3 |
| 五个已装配技能 | **Q / W / E / R / T** |
| 招架 / 回避 / 迎击 | Z / X / C |
| 药剂 / 防御 | **V / F** |

进度、音量、已解锁角色与战绩保存在当前浏览器，不同地址或浏览器互不共享。远征保存章节、路线、事件、对白、阵容、奖励、五槽装配与当前战斗。当前远征存档为v4、战斗存档为v8。旧版远征v1–v3会迁移并保留原六战路线与完成记录，开始新远征才能体验分支。旧战斗v1–v7可迁移；旧四槽补入第五技，雷克旧±3平衡按比例迁移到±10。旧版六格念线和充能按库存比例迁移到新容量，记录保留原数量；旧战斗不凭空补发AP结余。无效战斗返回本章整备。本地文件的存档可用性取决于浏览器设置。

## 场景、模型与声音

雾蚀遗迹供刃卫、司祭和巨人使用；风暴栈桥供雷脊守卫使用；沉星圣所供织者、执行官和最终BOSS使用；新增工业水闸平台供监守和搬运者使用，星轨观测台供测绘仪使用，共五套真实三维环境。各战有正面迎击、纵队、侧翼或独狼对峙等编队。突进、回避与受击后退属于表现层，没有额外的前后排伤害或距离规则。角色模型会根据医生／船长及观测／收录状态切换对应外观。

标题页提供 **「角色模型展示」**：查看参照潜行立绘、通过Blender脚本制作的银焱战甲样件，可以旋转与缩放检查正面、背面、面部和装甲轮廓。它是可编辑的模型研究样件，不是单张立绘自动恢复出的原始三维模型。

- Blender源文件：[qianxing-reference-study.blend](assets_3d/qianxing/qianxing-reference-study.blend)
- 游戏模型：[qianxing.glb](public/models/qianxing.glb)
- 建模脚本：[build_qianxing.py](assets_3d/blender/build_qianxing.py)
- 正面、背面、侧面及面部预览位于 `assets_3d/qianxing/`。

四张图像覆盖标题背景、七人头像与船长形态。潜行使用上述Blender网格样件；其余角色、BOSS、场景、动画及特效延续程序化表现。新头像的生成记录见 [3.2 美术适配](docs/art-canon-3.2.md)。

362句对白与旁白均配有预制中文MP3。本轮复用263句，仅为新增99句生成配音。采用七种中文神经基础声线，按角色选择并调整语速和音高；游木和游墓使用不同基础声音。生成时通过第三方 edge-tts 客户端访问 Edge 在线服务，成品保存在本地。并非真人演员录制。游戏运行时播放本地文件，无需联网TTS；可以重听、关闭配音、自动推进或查看对白记录；标题页和对白下方都可打开「角色声音试听」。音乐和技能音效为程序合成。对白、原设依据和配音复现方法见 [剧情与配音说明](docs/story-and-voice.md)。

七名角色均使用现有原卡。本次救援支线、具体组队关系、除魔晶巨人外的九名BOSS及回合制数值属于demo适配。原始角色工作簿未修改。分支地图用于选择路线，当前没有自由行走探索、装备系统或联网功能。

## 开发与验证

需要Node.js 20.19+或22.12+。在本目录执行：

```sh
npm install
npm run dev
```

```sh
npm test          # 战斗、存档、远征、悬浮说明与语音检查
npm run build    # 常规网页发行文件，输出 dist/
npm run offline  # 重新生成独立的「开始游戏.html」
```

修改源码后需重新生成离线文件。战斗规则在 `src/combat.js`，新角色技能在 `src/expedition-heroes.js`，BOSS与奖励数据在 `src/encounters.js`、`src/rewards.js`，剧情在 `src/story.js`。`src/scene.js` 管理三维表现，`src/main.js` 连接界面与流程，`src/audio.js` 管理音乐和音效，`src/voice.js` 管理对白音频。

修改对白后，在安装了 `edge-tts` 与 `mutagen` 的 Python 构建环境运行以下命令，再打包游戏。配音默认逐句复用：新增或修改哪句就配哪句；没有变化时不联网、不重写素材。`npm run build` 和 `npm run offline` 只打包已有音频，不会重配。选声、完整重配与离线回归检查见 [剧情与配音说明](docs/story-and-voice.md)。

```sh
python scripts/generate-neural-voices.py --dry-run  # 预览复用和待生成句数，不联网
python scripts/generate-neural-voices.py            # 只生成变化的句子
```

新版阵容的六BOSS探针可运行 `node scripts/new-roster-probe.mjs`。它只使用公开的玩家操作，不改血量、资源或AP；探针通关不等于已经完成浏览器表现与离线文件验收。
