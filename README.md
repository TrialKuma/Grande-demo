# 格朗德 · 魔晶回响 3.2

六章回合制远征 demo《停机之前》。七名考察队员被困在博洛伦地下；同行者需要恢复通风、查明旧设施故障，打通撤离路线，把人带回来。考察队与七位可用角色是两组不同的人，游墓是游木体内的另一人格，不额外占用队伍位置。

本版有 **6 名 BOSS、7 名可用角色、每人 5 个技能槽、3 套三维战斗场景、21 项成长奖励、263 句配有中文合成音频的剧情对白与旁白**。可以连续远征，也可以在单场试炼中直接挑战 BOSS。

## 直接开始

**双击本目录的「开始游戏.html」，使用 Chrome 或 Edge 打开。** 修改源码或资源后，需先运行 `npm run offline` 更新这个独立文件。

从 GitHub 下载时，点击 **Code → Download ZIP**，解压后打开「开始游戏.html」。仓库中的 HTML 源码预览页不能直接运行游戏。

离线构建会内嵌游戏代码、四张美术图集、三维引擎、潜行 GLB 模型、263 段对白 MP3、音乐与音效。生成后可以只复制这一文件，无需安装依赖、登录或联网。浏览器需要支持 WebGL 2；声音需要首次点击授权播放。当前版本的集成验收范围见 [3.2 更新说明](docs/update-3.2.md) 与 [验证报告](docs/test-report.md)。

开发预览地址为 `http://127.0.0.1:4173/`，仅在本机服务运行期间有效。首次游玩可选「初探」熟悉机制；「标准」需要安排应对与恢复，「险境」进一步增加压力。三档保留完整机制。

## 六章远征

| 顺序 | BOSS | 战斗重点 | 战后进展 |
| --- | --- | --- | --- |
| 1 | 折镜刃卫 | 魔法拆镜，物理趁隙爆发；观察剑招预告 | 打开入口，游木／游墓加入 |
| 2 | 孢冠司祭 | 物理连击清孢，魔法攻击裸冠 | 哈特蒙斯加入，恢复联络与空气 |
| 3 | 雷脊守卫 | 物理泄电，保护队员并应对风暴 | 潜行加入，恢复栈桥线路 |
| 4 | 魔晶巨人 | 应对解体地裂，驱散迷雾，以双系命中净化核心 | 接触被困考察队，补丁Z加入 |
| 5 | 缄页织者 | 随封页切换攻击系别，保护施法资源 | 查明事故，取得停机指令 |
| 6 | 归零之核 | 双系交替拆屏障，接入核心并守住最后放电 | 撤离考察队，完成远征 |

每章按 **战前对话 → 战斗 → 战后对话 → 奖励 → 整备** 推进；终章战后直接进入结局。对白可逐句阅读、返回上一句、查看记录、重听、自动播放或跳过，位置自动保存。

前四战各从四项奖励中选一项，第五战从五项中选一项：**21 项投放内容，一次远征获得其中 5 项**。第一至第四战后依次开放四、五、六、七人选三。整备时可以替换队员和技能；下场补满生命、药剂，并恢复各角色的初始战斗资源。战败可重整本章，已经获得的奖励与同伴保留。

## 角色与施法资源

只使用四类基础施法资源：**气息、连击、平衡、魔力**。直感、剑势、标本、船长接管、记录、护盾与反击待发作为角色状态显示。

| 角色 | 资源与基本循环 | 成长方向 |
| --- | --- | --- |
| 尼布斯拉姆 | 气息初始10、每轮回2；射击积累直感，满层强化重型射击或迎击；掩护射击提供队伍护盾 | 三段射击、满直感强化、对标记目标追击 |
| 艾佩莉雅 | 连击初始0；交替物理与魔法强化伤害、削韧和连击获取；战术重整主动准备连击 | 低耗交替、多段爆发、满足条件时降低AP |
| 雷克老板 | 平衡初始0，范围 **−10至+10，每轮向0回2**。肉身同调强化自身与剑势，剑式偏正；缚足同化削弱敌人，咒弹偏负；领域换向主动切换路线 | 归零、低AP自身同调、物理清账三连 |
| 哈特蒙斯 | 魔力初始10；书页攻击、心智通路安抚与保护队友；心念锚定提供低耗自身护盾 | 同伴先行动后强化安抚，有盾时强化书页 |
| 潜行 | 魔力初始10；物理钉刺、银焱魔法、自身装甲与修复；脉冲射线提供低耗魔法衔接 | 有盾时强化光束，队友先行动后扩大装甲保护 |
| 游木／游墓 | 气息初始10、每轮回2；手术刀准备 → 切除护层 → 同槽变为移植。生命不高于40%时，每战可接管一次并换成船长技能 | 精密缝合、强化移植、提高接管时护盾 |
| 补丁Z | 魔力初始10；钥刃选择观测、书阵选择收录。每支付2魔力积累1记录，施放前达到3／6条时自动变招 | 时之扉、强化招式削韧、厚页书阵 |

所有魔力技能都必须**先支付足额魔力，施放成功后返还2点**；标价6时，持有4点仍不能施放。魔力不会自动随回合恢复，整备技能要花AP。哈特与潜行有回复1魔力的免费基础攻击；补丁Z在观测中每轮第一次攻击额外回魔1，收录中每轮首次受击增加1记录，书阵护盾被敌方击破时回魔2并反击一次。

**补丁Z的记录不能代替魔力支付技能。** 它是自动强化条件：先按已有记录决定变招、消耗对应记录，再由本次实际支付的魔力生成新记录。这是对原版魔力时钟稿的收束，没有接入原稿的额外回合与免费无限行动。

游木只切除镜片、孢压、蓄电、封页或迷雾，不能偷取BOSS阶段、抗控或核心规则。船长接管持续两轮、承伤减少35%，仍可能倒下；炮击可以提前结束。退出后虚脱两轮，输出减少20%、承伤增加20%，仍能治疗与使用药剂。

每人默认有 **5 个可用技能**，奖励可解锁第6个；每场始终装配5个。新技能自动放入第5槽（T），可在整备时调整。雷克的强化剑枪、游木的切除／移植与船长技能、补丁Z的断光／镜反／裂片／断面会直接在原技能槽变名，高亮并显示当前效果。

## 战斗操作与信息

- 全队每轮固定共享 **6 AP**，三名队员的15个已装配技能同时显示。可直接点任意队员的技能；头像选择决定快捷键、药剂、防御与应对的执行者。
- **技能按钮显示实时削韧值**。悬浮技能查看伤害、段数、资源支付与返还、当前变招和限制；悬浮头像查看整体机制，悬浮BUFF图标查看状态。
- 右侧预告显示敌招、目标与伤害。花1 AP准备招架、回避或迎击，改选免费；下一轮仍固定恢复6 AP。
- 群体主招的招架减伤30%、回避减伤60%，需要结合护盾、防御、拆层或恢复；迎击承担更多伤害换反击。应对只覆盖主招，不覆盖另行追加的攻击。
- BOSS韧性上限为 **160**。玩家阶段破韧取消敌人当轮行动并提供50%增伤；敌人已出手后由应对造成的破绽在下一玩家回合提供增伤，**敌人仍会出招**。恢复架势后有一整轮抗控。
- 药剂和普通防御各消耗1 AP。每场3瓶药剂，可治疗或救起选中的队员。普通防御只保护该队员。
- **B** 打开六名BOSS的游戏内招式档案；**H** 查看通用规则。拖动战场可围绕BOSS水平旋转360°，滚轮缩放，镜头重置按钮恢复初始视角。
- 本版保留已有BOSS伤害，不因新增治疗或角色而降低敌人攻击。更多保护手段仍须占用输出、回资源和应对所用的同一组AP。

魔晶巨人的核心须在期限内完成物理、魔法各3次命中，多段逐段计算。最终BOSS耗尽生命后进入停机过载：各命中至少一次物理与魔法，准备任意应对，再结束回合守住最后放电。仅打空生命不会直接获胜；超时会重组。逐招数值以游戏内预告与BOSS档案为准。

| 操作 | 快捷键 |
| --- | --- |
| 选择队员 | 1 / 2 / 3 |
| 五个已装配技能 | **Q / W / E / R / T** |
| 招架 / 回避 / 迎击 | Z / X / C |
| 药剂 / 防御 | **V / F** |
| 结束回合 | 空格 |
| 暂停与设置 | Esc |
| 通用规则 / BOSS招式手册 | H / B |
| 推进对白 | 空格 / Enter |
| 旋转 / 缩放镜头 | 拖动战场 / 滚轮 |

进度、音量与战绩保存在当前浏览器，不同地址或浏览器互不共享。远征保存章节、对白、阵容、奖励、五槽装配与当前战斗。当前远征存档为v3、战斗存档为v5；旧版远征v1/v2和战斗v1–v4会迁移。旧四槽保留并补入实用第五技，雷克旧±3平衡按比例迁移到±10；无效战斗返回本章整备。本地文件的存档可用性取决于浏览器设置。

## 场景、模型与声音

雾蚀遗迹供刃卫、司祭和巨人使用；风暴栈桥供雷脊守卫使用；沉星圣所供织者和最终BOSS使用，共三套真实三维环境。新增角色模型会根据医生／船长及观测／收录状态切换对应外观。

标题页提供 **「角色模型展示」**：查看参照潜行立绘、通过Blender脚本制作的银焱战甲样件，可以旋转与缩放检查正面、背面、面部和装甲轮廓。它是可编辑的模型研究样件，不是单张立绘自动恢复出的原始三维模型。

- Blender源文件：[qianxing-reference-study.blend](assets_3d/qianxing/qianxing-reference-study.blend)
- 游戏模型：[qianxing.glb](public/models/qianxing.glb)
- 建模脚本：[build_qianxing.py](assets_3d/blender/build_qianxing.py)
- 正面、背面、侧面及面部预览位于 `assets_3d/qianxing/`。

四张图像覆盖标题背景、七人头像与船长形态。潜行使用上述Blender网格样件；其余角色、BOSS、场景、动画及特效延续程序化表现。新头像的生成记录见 [3.2 美术适配](docs/art-canon-3.2.md)。

263句对白与旁白均配有预制中文MP3。采用七种中文神经基础声线，按角色选择并调整语速和音高；游木和游墓使用不同基础声音。生成时通过第三方 edge-tts 客户端访问 Edge 在线服务，成品保存在本地。并非真人演员录制。游戏运行时播放本地文件，无需联网TTS；可以重听、关闭配音、自动推进或查看对白记录；标题页和对白下方都可打开「角色声音试听」。音乐和技能音效为程序合成。对白、原设依据和配音复现方法见 [剧情与配音说明](docs/story-and-voice.md)。

七名角色均使用现有原卡。本次救援支线、具体组队关系、除魔晶巨人外的五名BOSS及回合制数值属于demo适配。原始角色工作簿未修改。当前没有自由探索地图、装备系统或联网功能。

## 开发与验证

需要Node.js 20.19+或22.12+。在本目录执行：

```sh
npm install
npm run dev
```

```sh
npm test          # 战斗、存档、远征、悬浮说明与语音检查
npm run build    # 常规网页发行文件，输出 dist/
npm run offline  # 重新生成独立的「开始游戏.html」
```

修改源码后需重新生成离线文件。战斗规则在 `src/combat.js`，新角色技能在 `src/expedition-heroes.js`，BOSS与奖励数据在 `src/encounters.js`、`src/rewards.js`，剧情在 `src/story.js`。`src/scene.js` 管理三维表现，`src/main.js` 连接界面与流程，`src/audio.js` 管理音乐和音效，`src/voice.js` 管理对白音频。

修改对白后，在安装了 `edge-tts` 与 `mutagen` 的 Python 构建环境运行以下命令，再打包游戏。配音默认逐句复用：新增或修改哪句就配哪句；没有变化时不联网、不重写素材。`npm run build` 和 `npm run offline` 只打包已有音频，不会重配。选声、完整重配与离线回归检查见 [剧情与配音说明](docs/story-and-voice.md)。

```sh
python scripts/generate-neural-voices.py --dry-run  # 预览复用和待生成句数，不联网
python scripts/generate-neural-voices.py            # 只生成变化的句子
```

新版阵容的六BOSS探针可运行 `node scripts/new-roster-probe.mjs`。它只使用公开的玩家操作，不改血量、资源或AP；探针通关不等于已经完成浏览器表现与离线文件验收。

当前更新范围见 [3.2 更新说明](docs/update-3.2.md)，集成验收结果见 [验证报告](docs/test-report.md)。`docs/design.md`、`docs/design-v2.md`及3.1文档保留作历史参考；现行规则以3.2游戏内说明为准。
