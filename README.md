# 格朗德 · 魔晶回响 3.9

带有分支路线的回合制远征 demo《停机之前》。六位学生和一位老师被困在博洛伦地下，救援队需要恢复通风、打开通道，把七人带出来。被困考察队与七名可用角色是两组不同的人；游墓是游木体内的另一人格，不额外占队伍位置。

目前有 **7 名角色、10 名正式 BOSS、3 种入门敌人、2 种途中编队、5 套三维战场、35 项成长奖励和 297 句本地中文配音**。一次新远征经过三场入门战、八场正式 BOSS 战与三场途中编队战，共十四场；两处分支与战间事件影响准备条件和三种结局。

**3.9 的重点是让角色能力更有区别，并把战后部分变成可以走动的短间章。** 尼布斯监视敌人并在其出手前截击，艾佩莉雅闪开第一段攻击，哈特把敌人的单体攻击转向敌队，补丁记录并干扰预告。部分战斗有多名敌人，目标选择与群攻开始有实际用途。招募按剧情分批进行；正式关卡的同伴至少有四项基础技能，不再以两招加入后期战斗。

具体规则见 [3.9 更新说明](docs/update-3.9.md)、[角色玩法指南](public/play-guide.html) 和 [验证报告](docs/test-report.md)。较早版本的更新文档保留作历史记录，现行说明以 3.9 代码和游戏内信息为准。

## 开始游玩

运行 `npm run offline` 即可在本地一键生成独立单文件 **「开始游戏.html」**，使用支持 WebGL 2 的 Chrome 或 Edge 打开。离线构建会把代码、美术、模型、概念图、环景、全套配音和 BGM 原声直接内嵌进 HTML，生成后可单文件拷贝离线畅玩，不需要账号或联网服务。声音需要第一次点击后才能播放。

开发服务运行时可直接访问 `http://127.0.0.1:4173/`，网页版玩法文章在 `/play-guide.html`。进度按浏览器和地址分别保存，其他端口的验收不会同步覆盖这个地址的存档。

「初探」适合熟悉机制；「标准」需要分配进攻、恢复与干扰；「险境」进一步增加压力。三档均保留机制。独狼是另行配置数值的单场挑战，故事远征仍按招募进度组成一至三人的队伍。

## 远征、招募与技能学习

| 入门战 | 学习重点 | 战后变化 |
| --- | --- | --- |
| 巡路残机 | 尼布斯单人，两招，基础 3 AP | 学会掩护射击；艾佩莉雅与雷克二选一先到场 |
| 松动石卫 | 两人共用基础 4 AP，安排资源与防护 | 出战角色继续学习基础技能 |
| 失控导流器 | 把准备、攻击与保护接起来 | 先前留在后方的艾佩莉雅或雷克加入，组成三人队 |

教学阶段逐步开放技能。**进入正式 BOSS 流程前，已经招募的人补齐至少四项基础技能；之后新加入的人也从至少四项开始。** 第五项可通过一次参战胜利、间章操练或整备中的个人演练学会。旧存档已学会的技能不会收回。

| 正式流程 | 战斗重点 | 战后与招募 |
| --- | --- | --- |
| 折镜刃卫 | 拆镜、观察剑招 | 与内门联络灯互动；清理巡防小队后，哈特／游木二选一 |
| 孢冠司祭 | 处理孢压与菌簇，比较集中攻击和群攻 | 恢复通风；哈特／游木中尚未同行的一人赶到 |
| 雷脊守卫 | 泄电、保护目标、处理风暴 | 放下栈桥并拦住巡防小队；潜行／补丁二选一 |
| 水闸监守／熔炉搬运者 | 两条路线分别处理水压或炉温 | 操作设备，安排途中救援或设施工作 |
| 魔晶巨人 | 解体、迷雾与双系核心命中 | 联系避难室；潜行／补丁中尚未同行的一人赶到 |
| 缄页织者 | 封页与护卫，先拆保护还是直接突破 | 核对门禁；清理三敌中继哨站 |
| 星轨测绘仪／缄令执行官 | 打乱预测或处理轻重击令 | 保存时序或撤销追击，选择最后准备的重点 |
| 归零之核 | 拆除屏障，满足停机条件并守住放电 | 手动开门，救出考察队，进入对应结局 |

每次招募只出现附近一至两名合理人选，旧版已经招募的其他顺序仍可继续。队伍最多三人，后加入的角色在整备界面换入。第一、第三场入门战各增加一个出战位置，其余招募增加可轮换的同伴。

正式流程大致为 **战前短对白 → 战斗 → 可行走间章 → 招募或事件 → 随机三选一 → 整备**。刃卫、雷脊守卫和织者之后另插入编队战；最终战后直接进入撤离与结局。三场途中战只提供学习和后续补给，不多发成长选项。正式流程前七名 BOSS 各发一次奖励：每次随机三项，选一项，本次远征共获得七项，读档不会重抽。

整备会恢复下一战所需的生命、药剂及初始资源。可以拖动技能交换位置，或把技能库中已解锁的招式拖入技能位；点击技能位再选招式也可以。最多携带五项，教学与刚加入时可以少于五项。奖励解锁的可选技能仍须与已有技能取舍，不会无限增加出战按钮。

个人演练和间章操练只学习尚未掌握的基础技能；不会刷主线胜利、永久随机成长或 BOSS 自由挑战。每处间章操练只能完成一次，五项基础技能学齐后，个人演练不再开放。

## 可以走动的战后间章

间章复用回廊、泵站和档案区三种小布局，按当前故事替换人物、装置和目标。使用 **WASD／方向键**走动，靠近后按 **E** 互动；也可以点击目标让角色走过去，再明确互动。

每处只要求处理一个主要装置，必需对白约四至五句。和同伴聊天、顺手操练是可选内容。主要事情完成后，走到出口并互动才会推进，不会碰到边缘就自动离开。

教学对白每段五至七句；正式战前对白保留短篇幅。普通对白和探索交谈均可点击非交互空白处推进，探索交谈也提供重听、配音开关和播放状态。位置、已完成目标与当前句会保存；返回标题后可以继续。

当前是连接战斗的小型可行走片段，还没有开放世界、寻宝、随机地图或独立的探索战斗系统。

## 七名角色的玩法

只使用四类基础施法资源：**气息、连击、平衡、魔力**。念线、充能和记录属于魔力角色各自的二级资源；直感、剑势、标本等作为状态显示。

| 角色 | 当前重点 |
| --- | --- |
| 尼布斯拉姆 | 射击积攒直感，标记帮助队友爆发。掩护射击盯住指定敌人，在它出手前截击；击杀或打断取消攻击，否则压低该次伤害。它不再生成护盾。扩散弹覆盖全部敌人。 |
| 艾佩莉雅 | 物理／魔法交替积攒连击，六点连击兑换重招。伊甸集中处决，哨兵覆盖敌队。战术重整回复生命与连击，并闪开本轮受到的第一段攻击；后续段仍会命中。 |
| 雷克老板 | 平衡范围 −10 至 +10，每轮向零回复两点。肉身同调强化自己与剑势，负域削弱敌人并制造易伤；换向负责切路线，不附赠廉价保护。 |
| 哈特蒙斯 | 最多四条念线。心智安抚把所选敌人的一次单体攻击引向另一名敌人；群攻或只剩一个敌人时，降低这次伤害。锚定为队友下次攻击增幅，回响负责集中输出与驱散。 |
| 潜行 | 最多三格充能。一格脉冲高效回魔、驱散强化，还能打断供能装置；多格光束用于集中突破。钉刺护甲保护自己，群体耀光与单体光束按目标数量取舍。 |
| 游木／游墓 | 清创准备切除并预备受伤后的包扎，必须先活下来才能包扎。切除挂创口并取走可移除的护层；移植、即时急救和持续缝合分别处理不同的恢复需求。血誓献血至四成生命，主动请船长接管并嘲讽。 |
| 补丁 Z | 最多十条记录。观测偏攻击；收录中的充能斩写下所选敌人的预告，让它本轮最后行动、降低伤害并取消治疗、召唤、供能或抽取资源等附效。核心与终幕规则仍须正常处理。 |

三名魔力角色的魔力上限都是十，不随回合自动回复。先花魔力准备二级资源，再消耗二级资源触发被动回魔：哈特消耗 1／2／3／4 条，返还 3／4／5／5 魔力；潜行消耗 1／2／3 格，返还 4／5／6；补丁每次消耗记录的行动在观测返还 2、收录返还 3。**少量多次的回魔效率较好，大量兑现换取更强效果。** 多段和群攻不会重复收取费用或重复回魔。

三项批量准备都是 2 AP 的纯转换：哈特用 8 魔力编四条念线，潜行用 9 魔力装满三格，补丁用 8 魔力写六条记录。正式阶段的四招已包含基本循环，这些后续大额准备提供新的回转选择。资源耗尽时的应急转换只做准备，不夹带原技能的战斗效果。

## 战斗操作与信息

- 一／二／三人故事队伍每轮基础 AP 为 **3／4／6**，独狼挑战基础 **5**。最多保留两点剩余 AP 到下一轮，分别最多 5／6／8／7；不是每轮额外白送两点。
- 部分战斗有多名敌人，各自有生命、韧性、状态与行动预告。先选择目标，再用技能；主敌倒下不代表整场结束，剩余敌人仍会行动，全部击败才胜利。
- 点击敌人模型或敌人条目选择目标；**Tab／Shift+Tab**切换敌人。群攻分别对存活敌人结算，角色资源、行动点和被动回魔仅按一次行动支付和返还。
- 技能卡标注物理／魔法／辅助、费用与实时削韧。悬浮技能看完整效果，悬浮头像看角色机制，悬浮状态图标看条件和期限。
- 防守由角色技能承担，没有额外的通用招架、回避、迎击或普通防御按钮。减伤取当前最高值，持续至本次敌方回合结束；敌方弱化可与角色减伤配合。
- 每批护盾分别持续两次敌方回合，先消耗快到期的批次；新护盾不刷新旧盾，总上限 60。敌人跳过行动也会推进期限。
- 玩家阶段破韧可取消该敌人的当轮行动并打开增伤窗口。多敌场上其他敌人仍会行动；反击、抗控与特殊阶段以各自预告为准。
- 药剂消耗 1 AP，每场三瓶，可治疗或救起选中队员。没有独立的普通防御行动。

魔晶巨人的核心需要在期限内完成物理与魔法各三次命中，多段逐段计数。最终 BOSS 耗尽生命后仍要满足停机过载：完成物理与魔法命中、使用实际生效的角色防护，再结束回合守住放电。独狼对相关命中条件另有适配，避免单属性角色无法通关；具体数值以游戏内招式档案为准。

| 操作 | 快捷键或方式 |
| --- | --- |
| 选择队员 | 1／2／3 |
| 已装配技能 | Q／W／E／R／T |
| 选择敌人 | 点击敌人或条目；Tab／Shift+Tab |
| 药剂／结束回合 | V／空格 |
| 暂停与设置 | Esc |
| 规则／BOSS 招式档案 | H／B |
| 推进对白 | 非交互空白处／空格／Enter |
| 间章行走／互动 | WASD 或方向键／E |
| 旋转／缩放镜头 | 拖动战场／滚轮 |

战斗位移与前后站位主要用于表现，没有距离伤害或前后排加成；间章的移动、碰撞和互动距离则实际生效。

## 自然解锁、GM 与保存

标题或暂停菜单中的 **GM · 试玩开关**分别控制角色全开和十名正式 BOSS 全开，两者都能关闭。关闭角色全开后，保留真实招募；关闭 BOSS 全开后，只保留实际击败的正式 BOSS。当前战斗允许打完，之后校正队伍和重新挑战资格。教学敌人、途中编队及召唤单位不进入正式 BOSS 自由挑战名单。

开关本身不增加招募或胜利记录；GM 期间实际打赢的正式 BOSS 仍记录胜利。自然解锁的角色可在主界面查看属性、技能与机制，并用于自由挑战；重新开始一轮故事仍遵循分批招募。随机成长和学习进度属于当前远征。

**重置游戏进度**需游戏内确认，会清除本游戏远征、自由挑战、招募、战绩和 GM 状态，恢复尼布斯单人入门，保留声音偏好。

当前新远征存档为 **v6**，战斗存档为 **v10**。保存包括章节、分支、事件、招募、学习、阵容、装配、奖励、探索位置与目标、对白进度和进行中的战斗。旧 v5 远征迁移后保留已招募角色、已学技能和进行中的战斗数值；旧六战或八战远征继续原路线，不强行重排已完成章节。无效的战斗状态回到当前整备，已获成长不因此清空。

## 场景、模型与声音

五套战场包括雾蚀遗迹、雷暴栈桥、缄页书库、地下水工厂和破碎观星台。完整 Blender 场景和十名正式 BOSS 沿用 3.8 制作基础；每名 BOSS 有导出的待机、攻击和受击动画，共三十条真实关键帧片段。3.9 增加五张场景环景及平台下方地景，并接入多敌展示与可行走间章。环景是远景图像，不是可到达的三维地图。

标题的「场景与 BOSS 展示」支持切换场景、播放动作和查看概念图；「角色模型展示」可旋转、缩放检查潜行。潜行与 BOSS 都提供可编辑 Blender 原件；其余角色和小怪保留程序化造型。BOSS 使用分件关节动画，尚无完整柔性蒙皮、布料模拟和面部表演。模型源文件分别在 `assets_3d/qianxing/`、`assets_3d/boss-cast/`、`assets_3d/worlds/`。

**297 句**对白与旁白均使用逐句缓存的本地中文 MP3；本次复用 198 句，新增或改写 99 句，清理 33 条不再引用的旧音频。固定按角色选声，游木与游墓使用不同声音。生成过程通过 `edge-tts` 访问在线语音服务，成品不是演员录音；游戏播放时不需要联网生成。改一句只重配那一句，新增 BOSS 不需要重配整部剧情。

音乐和技能音效由程序合成。已有按攻击主题和目标材质区分的声音、环境粒子与逐段扣血反馈；场景、对话、战斗等音乐生成方向另见 [BGM 生成提示词](docs/BGM生成提示词.md)，提示词本身不代表已经接入外部生成音乐。

七名角色来自已有设定；救援支线、组队关系、除魔晶巨人外的九名正式 BOSS 及具体回合制数值属于 demo 适配。原始角色工作簿未修改。当前没有装备系统或联网功能。

## 开发与验证

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev      # 本机 4173 开发预览
npm test         # 规则、存档、流程、界面结构与资源检查
npm run build    # 网页发行文件，输出 dist/
npm run offline  # 生成可单独复制的「开始游戏.html」
```

玩法集中在 `src/combat.js`、`src/multi-enemy.js` 与角色技能模块；新远征在 `src/campaign-learning.js`，教学在 `src/tutorial-story.js`，间章数据和状态在 `src/interludes.js`。`src/main.js` 连接界面与流程，`src/scene.js` 和 `src/scene-exploration.js` 管理三维表现与行走。

修改对白后，在安装 `edge-tts` 和 `mutagen` 的 Python 环境执行：

```sh
python scripts/generate-neural-voices.py --dry-run
python scripts/generate-neural-voices.py
```

第一条只预览复用与待生成句数；第二条只生成变化的句子。`npm run build` 和 `npm run offline` 只打包已有配音，不会重新配音。

本轮自动测试已通过 **521／521**；公开玩家操作探针在 **160／160** 个配置中找到胜利路径，数据见 [3.9 战斗验证](docs/3.9-combat-verification.json)。这证明存在合法打法，不等同于玩家胜率或平衡性已经完成。实际界面已检查探索与保存、技能拖动、两敌与三敌攻击、掩护截击，以及五处场景和 360° 旋转，未记录浏览器错误。

网页构建与离线打包均通过。「开始游戏.html」为 **91,334,248 字节／87.10 MiB**，全部图像、模型、297 句配音及运行代码已内嵌，校验无外部资源依赖。本次离线验证是静态打包检查；本地 file 页面曾受浏览器访问策略限制，未把它记作直接打开游玩通过。完整范围见 [验证报告](docs/test-report.md)。
