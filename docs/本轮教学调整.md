# 入门流程与四技能配置

尼布斯的第一场技能改为 **直感发射、单发确认**。先让玩家试一次气息消耗，再用普通射击和回合恢复把气息接回来。巡路残机需要能承受第一轮的完整输出，避免刚看懂按钮就结束。

| 关卡 | 尼布斯可用技能 | 这一场的重点 |
| --- | --- | --- |
| 巡路残机 | 直感发射、单发确认 | 先花气息打重招，再用射击与回合恢复接续输出。 |
| 松动石卫 | 加入整息装填 | 恢复也需要行动点；和第一位同伴分配进攻机会。 |
| 失控导流器 | 加入掩护射击 | 看预告目标，在进攻与出手前反制之间取舍。 |
| 正式 BOSS 流程 | 已学扩散弹，可自由替换 | 每人携带四项技能，更多技能保留在营地技能库。 |

正式流程中，新加入的角色仍然直接掌握四项基础技能。之后学到的第五项基础技能或奖励新技是可选配置，不增加战斗按钮数量。新技奖励自动替换第四槽，也可以立即在营地拖动、交换或换回原技能。

旧存档保留同行角色、已学技能、奖励和路线。原来的五项配置保留前四项的顺序，第五项仍留在技能库。旧教学存档已经获得的整息装填、掩护射击不会被收回；缺少单发确认时补齐进攻循环。战斗中的生命、行动点和计时随存档继续。
