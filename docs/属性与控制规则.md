# 本轮属性与控制规则

这份规则对应当前可玩的网页版本。力量、智力、敏捷、意志是战斗中的加成状态：双方都从 0 开始，增益向上加，减益可以降到负数。角色卡原始数值仅保留为设定参考，不再作为隐藏的伤害或防御基础。

## 四项属性如何生效

| 属性 | 当前作用 |
| --- | --- |
| 力量 | 每段物理伤害增加相同点数。三段攻击增加 1 力量，总伤害最多增加 3。 |
| 智力 | 每段魔法伤害增加相同点数，同时作为魔法防御。穿透魔抗的技能忽略目标这部分防御。 |
| 敏捷 | 每段受到的物理伤害减少相同点数，与攻击方力量一比一抵消。 |
| 意志 | 提高眩晕、封术、行动封锁的抵抗概率。 |

通常每段伤害为「技能基础伤害＋攻击方力量或智力－目标对应防御」。例如力量 −4 会让每段物理伤害减少 4；目标敏捷 −4 则让每段受到的物理伤害增加 4。非零攻击最低造成 1 点；闪避和护盾可以把最终生命损失降到零。难度与独狼倍率在角色防御结算后应用。破韧、反击留下的破绽等少数强力机制仍保留百分比窗口。

技能悬浮框展示基础伤害与属性贡献，尚未扣除目标防御；实际扣血继续在技能卡、敌方预告与战斗反馈中展示。多段攻击逐段结算，因此攻击过程中拆掉镜片、封页等防御时，后续段会立即受益。

## 普通增益与减益

- 直感兑现：本次力量 +12、削韧 +12。交叉火力：本次攻击属性 +6、削韧 +6。
- 尼布斯截击：在目标出手前攻击；未打断时，使它这次行动力量、智力各 −18。
- 雷克负域：敌人下一次进攻力量、智力各 −8、意志 −4；两轮内敏捷、智力各 −8。
- 心智安抚：目标这次进攻力量、智力各 −16；存在其他敌人时仍可将单体攻击转向它们。
- 常规防护姿态：增加敏捷、智力和意志。较弱姿态为 +13/+8/+6，完整姿态为 +20/+13/+10。同类姿态取最高值。
- 战术增幅：下一项主动攻击增加力量与智力，施放时消费一次。反击和持续创口不消费，也不享受这份主动攻击增幅。
- 原“治疗抑制”改为“意志裂隙”，意志 −5，不再使治疗减半。

状态栏显示实际生效的属性变化和期限。同名临时状态刷新期限，不重复叠数值。护盾仍按每次获得的批次分别计算，两次敌方回合后到期。

## 控制检定

当前抵抗率为 **30%＋意志加成×5%－（控制强度−12）×2.5%**，四舍五入到整数百分比，限制在 5%～95%。面对强度 12 的控制，没有意志状态时有 30% 抵抗率；意志 +4 时为 50%，意志 −4 时为 10%。强度 18 的强控对零意志目标有 15% 抵抗率。

检定生成 1～100 的整数，点数高于抵抗率对应数值时控制成功。这是为 Demo 选用的适配公式。原工作簿采用“控制检定值超过目标相关抗性”的结构，并未规定这套百分比公式。

- 敌方连招中的控制强度为 10～12；角色强制停机的强度为 18。
- 眩晕限制下一完整玩家回合的技能；封术只限制魔法攻击，物理与辅助技能仍可使用。
- 净化技能和药剂可以解除控制与可净化的负面属性标记。即使生命已满，受控或带有负面属性标记时也可用药。
- 控制自然结束或被净化后，获得一轮短暂抗控，避免连续失去行动机会。破韧后的抗控规则继续保留。
- 检定使用随存档保存的随机状态。查看预览不会消耗随机数，读档后相同操作会得到相同结果。

## 连招与四槽配装

十位正式 BOSS 都增加了连招铺垫或追击；五位会施加可抵抗的眩晕或封术。连招标记放在 BUFF 栏，头顶预告显示连招角标。拆层、处理随从、净化标记或取消主招，可以阻止对应后续效果。详细组合见 [BOSS 连招调整](./BOSS连招调整.md)。

每人只携带四项技能；新手先学习进攻循环，再学习伤害应对。正式流程的新队员直接掌握四项基础技能，已学会的其他技能留在配置列表。魔力角色的普通攻击在没有二级资源时免费攻击，也不生成资源；持有二级资源时消耗一份强化，并由被动回魔。独立转换技能负责准备二级资源。默认四槽包含转换和兑现；自选配装不会悄悄替换技能，移除转换或所有小额兑现技能可能使资源循环中断。

独狼核心继续允许单一属性完成。最终 BOSS 的独狼屏障改为每次主动攻击拆一层，三次同步后增加 6 点攻击属性；一次多段技能只拆一次，反击与持续伤害不额外拆。小队仍需交替物理与魔法。

## 原始依据

角色数据来自工作区 `Ric-Others/角色设定等13个文件/角色设定/` 中七份角色表。多数表的力量、智力、敏捷、意志位于 E2/E3/E5/E6；补丁魔力版位于 B3/B4/B6/B7。游木表的括号数值为游墓，H14 说明形态切换属性。

用户提供的《战斗规则Ver1.0.xlsx》“规则-流程”页：K34/K38 为物理与魔法扣防结构，K40 为智力参与魔法防御，K42/K44 与 P42/P44 为控制检定和相关抗性，C23/C24 为控制限制行动阶段。本次按用户要求，把原 K36 使用力量的物理防御改为敏捷；体魄相关控制也合并为意志抵抗。原表 N47 的 1d10 属于闪避，不作为这次控制公式的出处。原始工作簿未修改。
