# 3.2 更新范围

本轮将远征扩为七人阵容、每人五槽、二十一项成长奖励，并加入可回听的263句中文合成音频。六名BOSS、三套场景、全队每轮6 AP与既有攻击伤害保持不变。

## 角色玩法

- **雷克老板**：恢复 −10 至 +10 平衡，每轮向0返回2。正域肉身同调提供自身护盾与剑势，强化近身物理剑式；负域缚足同化使敌方下一次行动伤害降低20%，强化魔法咒弹。领域换向主动切换路线；过零群盾／群疗保留。旧技能ID保留用于存档迁移，实际名称、武器和效果已更新。
- **游木／游墓**：使用气息。手术刀准备 → 切除 → 原槽变为移植；切除仅接受镜片、孢压、蓄电、封页、迷雾白名单，不复制BOSS阶段与抗控。低血接管每战一次，五槽全部变为船长技能，持续两轮；炮击可提前退出。接管减伤35%，退出虚脱两轮、输出−20%／承伤+20%，不采用原稿永久锁1生命或不可行动的代价。
- **补丁Z**：选择原版魔力时钟的观测／收录两姿态。记录按实际支付魔力积累，达到3／6后自动强化充能斩或碎屑；所有技能仍需足额魔力和AP。把原稿可直接支付技能的记录改为条件强化，是本次明确的适配；没有合并平衡版、连击版，也没有接入额外回合或免费无限行动。
- 其余四人的第五基础槽分别提供掩护射击、战术重整、心念锚定、脉冲射线；成长解锁第六技后，可以替换任一装配槽。

第一至第四战后依次招募游木、哈特蒙斯、潜行、补丁Z。前四次奖励各4选1，第五次5选1，每次远征仍只取得5份成长。

## 信息与操作

技能以Q/W/E/R/T操作，药剂移至V，防御保持F。三名队员的15个技能同时显示；条件变招直接替换原槽名称、图标、效果和削韧预览。头像与BUFF悬浮说明同步展示平衡路线、标本、船长持续时间、虚脱、记录及书阵反击。

战斗镜头围绕中心BOSS水平旋转360°，支持缩放与重置。标题页新增潜行的角色模型展示；Blender可编辑源文件为 [qianxing-reference-study.blend](../assets_3d/qianxing/qianxing-reference-study.blend)，运行时模型为 [qianxing.glb](../public/models/qianxing.glb)。这是参照立绘制作的造型样件，其余角色和环境仍沿用程序化表现。

## 剧情与配音

六章共263句对白与旁白，交代救援起因、阶段目标、四次招募与事后处理。每句对应本地MP3，按角色选择七种中文神经基础声线，在线生成后保存为本地MP3；部分角色共享声线，但游木与游墓采用不同基础声音。人物情绪仍受合成语音限制。支持逐角色试听、上一句、重听、配音开关、自动推进与对白记录；详见 [剧情与配音说明](story-and-voice.md)。新角色图集及提示词见 [美术适配](art-canon-3.2.md)。

## 保存与验证边界

当前战斗存档v5、远征v3。旧战斗v1–v4与远征v1/v2继续迁移；旧四槽装配按原顺序保留并补第五槽，旧±3平衡按比例转换到±10，既有章节、奖励与同伴不清空。

当前全量228项检查通过，包括战斗、存档、远征、动态悬浮说明和字幕／音频对应。两套新阵容各以公开玩家操作跑完六BOSS，共12场胜利；这些策略使用了应对、治疗和主动回资源，不代表只输出也能通关。

浏览器已检查实际战斗、对白与试听控制、模型旋转以及独立HTML内嵌资源。具体观察与仍有的表现限制见 [验证报告](test-report.md)。
