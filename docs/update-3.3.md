# 3.3 · 岔路与同行者

在已归档的 3.2 版本上继续扩展。角色仍采用已有的七人设定，基础施法资源仍为气息、连击、平衡和魔力。

## 关卡与选择

共有十名不同 BOSS。新远征有八场战斗，在两处分岔各选择一条路：

折镜刃卫 → 孢冠司祭 → 雷脊守卫 → **水闸监守／熔炉搬运者** → 魔晶巨人 → 缄页织者 → **星轨测绘仪／缄令执行官** → 归零之核。

- 水闸监守通过水位强化攻击，连续命中和正确应对可以排水。
- 熔炉搬运者会积累炉热，排汽后出现炉门敞开的攻击窗口。
- 星轨测绘仪会记录上一项攻击技能；重复同一招会提高锁定，换招可以打乱预测，降低贯星与轨道坍缩的伤害。
- 缄令执行官会交替公布轻击令和重击令；违令会提高判罚，符合要求的攻击和战术操作可以控制风险。

每次分支战后都有间章事件。玩家可安排救援、整理证据或维护设施，选择会实际影响下一场战斗的开场状态，并累计到最终的救援交接、调查立案、设施改建三种收尾。所有结局都在完成救援之后展开。

剧情保留原有六章的对白，补入选路回应、四场分支战前后对话、六种事件回应和三段结局，共 362 句中文配音。新增 99 句，原 263 句直接复用；角色声线沿用最新选角，包括哈特蒙斯的成年青年男声。

## 操作与表现

对白期间点击非交互区域即可推进。按钮、选项、文字选择和镜头拖动不会误触下一句，原有按钮与键盘操作仍可使用。

十场战斗使用不同的编队，包含正面迎击、狭窄栈桥纵队、侧翼展开和独狼对峙。增加水闸工业平台和星轨观测台两套场景，共五套环境。四名分支 BOSS 有各自的程序化模型。

近战突进、回避侧移、命中后退属于表现层。当前没有前后排伤害修正、距离费用或格子移动规则；这些动作不会暗中改变技能数值。

## 独狼与存档

自由挑战可以切换三人队伍或独狼模式。独狼使用已解锁角色，每场保留五个技能位；每轮五点行动点，敌方生命为同难度小队模式的 64%，伤害为 90%，韧性上限 120、每轮恢复 10。魔晶核心需要任意属性命中四次；归零终幕需要任意属性命中两次，并准备应对、存活至放电结束，避免单属性角色无法完成机制。规则也在选择界面说明。

三档难度、七位角色、十名 BOSS 的 210 场公开操作探针全部完成；仅输出策略仍会在多数标准独狼战斗中败北。它证明存在可行通关路径，不代替玩家对难度的评价。数值依据与复现见 [3.3 平衡报告](balance-3.3.md)。

旧远征存档继续原来的六战路线，保留章节、角色和成长，已通关的记录仍算通关。开始新的远征即可体验八战分支路线。独狼存档记录自己的模式，重新挑战不会变回三人队伍。
