# 格朗德 · 魔晶回响：设计与改编记录

## 预期体验

5–10 分钟内完成一场可以理解、可以失败、可以重新挑战的 BOSS 战。核心决策为「这一轮把六个行动点给谁」以及「用资源爆发，还是留出打断和保护」。自由切换小队、透明敌方预告和不依赖随机命中的数值，让失败能归因到具体选择。

美术采用暗色遗迹、低多边形三维模型、紫色魔晶与青金点光。固定编队构成桌面战术场景，支持有限镜头旋转、缩放。标题页及头像使用独立生成的图片，战场是真实三维场景。

## 原始资料

- `../Ric-Others/尼布斯拉姆.md`：气息、直感射击、单发确认、扩散装弹与左轮武器。
- `../Ric-Others/艾佩莉雅.md`：女性机械人形、连击档位、圣餐螳螂刀、炼净双枪、伊甸之约及地狱哨兵。粉色长发与黑白粉机械装束见该角色的原参考图。
- `../Ric-Others/雷克老板.md`：人形原生深渊种，酒保/驱魔师，深渊领域投影、领域同化、正负平衡。没有现成具体技能表，故本次补写四招。
- `../Ric-Others/怪物设计示例-博洛伦魔晶巨人.md`：每 20% 生命解体、随伤加速、碎片飞散、可打断地裂、迷雾孢子、魔晶共鸣、元素回收、核心三物三魔与两回合重组。

以上路径相对于工作区的游戏目录，原稿保持原样。本 demo 的组队、服装和新招式不意味着用户已确认其成为正式设定。

## 改编表

| 原设方向 | Demo实现 |
| --- | --- |
| 每个角色每回合 4 行动点 | 队伍共享 6 点，减少重复动作并加强选择 |
| 骰点伤害 / 命中补正 | 确定性伤害，技能上明示数值 |
| 尼布斯的装填追加行动 | 合并装填与射击；气息起始 8，普攻 +1，每轮 +2 |
| 艾佩莉雅的 ALS 与档位体系 | 起手积累连击，四连斩/狙击消耗连击，保留物魔切换 |
| 雷克的领域和平衡框架 | 咒符回响 +1、负域禁行 −2、正域庇护 +2、领域同化 −2 |
| 巨人的低意志、易受控 | 100点韧性；破韧跳过本轮并易伤50%；禁行可直接打断地裂 |
| 每20%生命元素解体 | 共四个阈值，飞散碎片并蓄力地裂；已破韧时不能重新蓄力 |
| 生命降低后增加行动数 | 一次主动行动，解体后追加碎岩飞弹，三次解体后再追加真空波 |
| 技能按权重抽取 | 重击→迷雾→连弹→压缩→回收，循环预告；地裂和破韧拥有更高优先级 |
| 魔晶共鸣兼具增益与危险 | 简化为层数危险；物理受击及迷雾叠层，5层触发震荡，领域可驱散 |
| 魔法抗性 | 18%减伤；地狱哨兵穿透，核心只计命中 |
| 核心两回合后重组 | 曝光余轮不扣期限，再给两个完整回合；失败恢复28%躯壳，可再次尝试 |
| 三次物理与三次魔法 | 按真实伤害段数计数；击碎躯壳的攻击不会把溢出段数算作核心命中 |

## 首发数值

生命：尼布斯 170 / 艾佩莉雅 145 / 雷克 160。

Boss躯壳：初探 700，标准 900，险境 1150；敌方伤害倍率为 0.73 / 1.00 / 1.24。三种难度机制一致。

技能详见游戏手册或 `src/combat.js` 中 `SKILLS`。基础技能消耗1点，强技/治疗/团队保护消耗2点；所有动作有限行动点，不存在无限资源循环。护盾上限60，药剂3瓶。药剂允许救起任一倒下但尚未全队覆灭的队员。

## 已知取舍

- 单体敌人由系统自动锁定；玩家只需选择行动者。领域同化自动选最低生命比例的存活队员，药剂针对手动选中的队员。
- 3D演出期间暂时锁定战斗输入，速度可切换1×/2×。逻辑独立于动画，可进行确定性测试。
- 核心初次曝光时保留全队资源与剩余行动点，考验是否留出双系连携。失败重组后命中计数归零。
- 仅有一场战斗，没有混入额外角色、随机装备、刷材料等系统；先检验角色组合与Boss阶段是否有趣。
