# 3.7：从一个人开始学会战斗

新开「停机之前」会先进入三场简单实战，再接上原有八战分支远征。正式 BOSS 总数仍是十名，另有三种教学小怪；每个小怪只有普通攻击和一种特殊攻击。旧远征保留原来的六战或八战路线，不会突然退回序章。

## 先学两招，再决定谁来帮忙

开局只有尼布斯，携带直感发射和整息装填，基础行动点为 3。第一战后学会掩护射击，并从六名同伴中自选一位加入；两人共享 4 AP。第三战后再选一人，组成共享 6 AP 的三人队。之后击败折镜刃卫、孢冠司祭、雷脊守卫和魔晶巨人，各招募一位其余同伴。后来的角色可在整备时替换上阵。

每名新角色先有两项可循环使用的技能。参与一场胜利，或在整备中完成一次个人演练，就学会下一项基础技能，直到五项。演练不推进剧情、不发成长奖励，也不计入 BOSS 挑战解锁。先后加入有不同学习节奏，但晚加入的人可以通过演练补课。自由挑战保留完整基础技能，方便单独比较角色。

开 GM 可以自由查看和换用七名角色；新远征仍按一人到三人的节奏增加队伍位置。关闭 GM 后保留实际招募进度与已经取得的成长，正在进行的测试战斗可以打完。

## 对白与战后奖励

主线战前、战后各段压到 8–10 句。教学为战前 7 句、战后 4 句，分支为 7／5 句，短事件回应 3 句，结局 7 句。保留开局求救、救援目标、故障线索和收尾，未出战同伴可以通过救援频道发言。每句继续支持中文配音、空白处推进和回看；旧档对白游标超出压缩后的长度时会收拢到段落末句。

正式远征的前七场胜利各随机提供三项未获得的成长，三选一；三场教学通过学习新技能和招募奖励推进，不另外发一轮强化。随机结果随本次远征保存，普通读档不会刷新。三十五项成长保留为总投放池，一次远征获得七项。

哈特与潜行的大幅对话立绘按各自图集边界显示，修正原来旁边人物或黑边混入的问题。

## 用角色自己的技能防守

移除通用招架、回避、迎击及独立防御按钮，原快捷键也不再触发。防守与输出、准备资源共同使用角色技能位和 AP。

| 角色 | 基本防守选择 |
| --- | --- |
| 尼布斯 | 掩护射击提供全队 30% 减伤与护盾，兼顾进攻 |
| 艾佩莉雅 | 战术重整提供自身 55% 减伤，兼顾恢复和连击准备 |
| 雷克 | 肉身同调强化自身并减伤；负域削弱敌人，帮助全队 |
| 哈特蒙斯 | 逐条安抚提供自身 55%、队友 30% 减伤并压低敌方伤害，与念线回转结合 |
| 潜行 | 钉刺护甲提供自身 55% 减伤、护盾及物理反击，消耗原本可用于射线的充能 |
| 游木／游墓 | 清创整备提供自身 55% 减伤；血誓形态可嘲讽承伤 |
| 补丁 Z | 书阵提供薄盾；收录姿态兑现记录可以提供队伍保护 |

同类减伤只取最高值，持续到本次敌方回合结束；先减伤，再扣护盾。每批护盾仍分别保留两次敌方回合。敌方弱化可以与减伤配合。右侧显示当前保护，角色状态图标和技能悬浮框也显示具体数值与期限。

最终 BOSS 仍要求在终幕完成命中并活过放电，但原「准备通用应对」改为使用一项实际生效的角色防护技能。纯资源准备和应急提炼不算完成防守。

## 模型与场景

潜行保留黑发、银色分段战甲、蓝色内层和机械装置等特征，重做胸肩体积、甲片接缝、手臂装置、关节及头部。运行模型合并同材质网格，减少绘制开销；可从标题的「模型样件 · 潜行」旋转查看。

新制 Blender 细节库有二十个模块，包含十类环境构件和十套 BOSS 装饰。石拱、凹槽柱、管道、阀门、书庭构件、观测仪器等实际接入五套场景；BOSS 部件跟随头部、躯干或手臂动作，不是独立悬浮装饰。三种教学敌人使用各自的小型轮廓。

这些仍是参照立绘手工定义形体的风格化网格，不是从图片直接重建的高精度人物。脸部、头发、衣料和全身骨骼蒙皮仍有明显的提升空间。Blender 源文件、构建脚本与渲染图均保留在 `assets_3d`。
