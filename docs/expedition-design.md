# 远征篇 3.1 · 停机之前

六场战斗串起一次地下设施事故救援：七名考察队员被困，同行者需要恢复撤离路线，取得停机指令，在归零之核切断全区之前把人救出。本版有六名 BOSS、五名角色、三套场景、十五项奖励与八十六行战前战后对白。

人物取自 `Ric-Others` 原角色卡；事故、考察队及本次组队关系是 demo 原创支线，不替代正式世界观。人物写法与代表对白见 [角色与剧情适配](canon-adaptation.md)，外观依据见 [3.1 美术适配](art-canon-3.1.md)。

## 六章流程

| 章节 | 行动目标 | 遭遇 | 战后变化 |
| --- | --- | --- | --- |
| 十二个钟头 | 沿考察队最后的撤离路线进入地下 | 折镜刃卫 | 打开入口，第一次成长选择 |
| 先让他们喘口气 | 清除进风口孢子，接上被困队员的联络 | 孢冠司祭 | 哈特蒙斯加入 |
| 桥上有电 | 停下持续放电的守卫，恢复临时电路 | 雷脊守卫 | 潜行加入，电梯与通风恢复 |
| 就在门后面 | 清除避难室出口前的巨人，接触伤员 | 魔晶巨人 | 送入饮水和联络器，确认还需解除总控力场 |
| 批不了的停机单 | 通过拒绝停机的书庭，查明设施故障 | 缄页织者 | 取得停机指令，最后一次成长选择 |
| 门开了 | 打开核心防护、接入指令、守住最后放电 | 归零之核 | 七人撤离，伤员送医，核心关闭 |

每章按「战前对话 → 战斗 → 战后对话 → 奖励 → 整备」推进；终章战后直接进入完成页。对话可逐句阅读或跳过。哈特从第二战后、潜行从第三战后进入可选阵容；之后每场从已加入角色中选三人。对白中的同行队伍包括未上阵的同伴，他们负责联络、设施处理与撤离协助。

前五场各有三项固定奖励，每次选一项，共获得五项成长。下一场补满生命、药剂，恢复角色的初始资源，保留同伴、奖励及装配。失败可回本章整备后重试，不获得本场奖励、不跳关，也不损失先前成长。

## 五名角色与四类资源

| 角色 | 施法资源 | 在队伍中的作用 |
| --- | --- | --- |
| 尼布斯拉姆 | 气息，10 点上限、初始满值，每轮回复 2 | 稳定射击、标记与直感爆发；根据敌方预告保留直感用于迎击 |
| 艾佩莉雅 | 连击，10 点上限、初始 0 | 物理与魔法交替，拆除不同防护，积累连击后爆发 |
| 雷克老板 | 平衡，−3 至 +3、初始 0 | 由负过零给护盾、由正过零给治疗；安排领域移动与打断时机 |
| 哈特蒙斯 | 魔力，10 点上限、初始满值 | 书页投射与通路回响输出，心智安抚救治，奖励解锁全队协同防护 |
| 潜行 | 魔力，10 点上限、初始满值 | 物理钉刺与银焱魔法切换，自身装甲、物理受击反击与修复 |

魔力沿用原稿的先支付、后返还规则：付费技能须持有完整标价，成功施放后统一返还 2 魔力，不能用返还后的净消耗判断能否施放。哈特与潜行的基础攻击不耗魔力，并回复 1 点；各自整备技能每轮可回复 4 点，仍消耗行动点。魔力不随回合自动恢复。哈特使用书本与心智通路；潜行按原卡“雷克版”的魔力资源规则，将战甲钉刺、银焱和修复适配到四槽战斗。

直感、交叉火力、调和、护盾、钉刺反击等是具体状态或被动，不是第五类施法资源。钉刺反击最多储存两次，仅受到物理攻击时触发；护盾完全吸收伤害也可触发。

## 压力、应对与削韧

全队每轮固定 **6 AP**。技能、恢复、防御与战术应对共享这六点；准备应对消耗 1 点，改选免费，下轮仍恢复到六点。

BOSS 韧性上限为 **160**。玩家阶段将其打空，可以取消当轮敌招并得到 50% 增伤窗口。若是在敌人已经出手后由应对收益打空韧性，下一玩家回合获得“破绽”的 50% 增伤，敌人仍按照预告行动，不额外送出空过轮。架势恢复后有一整轮抗控，韧性最低保留 1，也不能直接打断。

三种应对有不同收益：招架提供削韧和针对招式的处理；回避降低承伤并帮助执行者恢复资源；迎击承担更大风险，换取伤害、削韧或拆层。单体应对按招式调整减伤；群体主招的招架减伤 30%、回避减伤 60%，需要继续安排护盾、普通防御、拆层与治疗。拆孢、泄电、交替拆屏障会改变危险招式压力，不能只看 BOSS 生命条。

技能按钮直接显示实时削韧值，悬浮详情补充伤害、段数、行动消耗、资源支付与返还、当前强化及限制。抗控、破绽与核心状态也进入预览说明。角色头像说明整体机制，独立 BUFF 图标说明当前被动与状态，右侧预告呈现应对后的预计承伤。

## 六名 BOSS 的决策重点

| BOSS | 主要决策 |
| --- | --- |
| 折镜刃卫 | 魔法拆镜后再安排物理爆发；避免在镜面反噬时连续硬打，按剑招选择保命、削韧或反击 |
| 孢冠司祭 | 用物理多段降低孢压，争取裸冠魔法输出；提前处理即将绽放的孢子 |
| 雷脊守卫 | 用物理命中泄电，同时决定将行动用于护盾、打断还是风暴后的反击收益 |
| 魔晶巨人 | 解体后准备地裂与追加攻击，处理迷雾和共鸣；核心出现后安排双系多段 |
| 缄页织者 | 根据本轮封页换系，提前拆封保护资源；治疗与重织招式仍带来攻击压力 |
| 归零之核 | 双系交替拆屏障并累积同步；为耗尽生命后的停机阶段预留资源与防护 |

具体招式、阶段变化、当前难度下的伤害与应对收益，以游戏内右侧预告及 **B 键 BOSS 档案**为准，不把逐招数值复制为另一份维护来源。

魔晶巨人核心要求物理与魔法各 3 次命中，多段逐段计入。归零之核耗尽生命后，必须各登记至少一次物理、魔法命中，准备任意战术应对，再结束回合承受最后放电，仍有队员存活方可胜利。玩家阶段触发时可用当轮剩余行动及后续两个完整回合；敌方阶段触发时从下一轮起计算。超时重组，可以再次尝试。

## 十五项成长奖励

每人有一项第五技能解锁和两项条件强化。新技能领取后加入技能库，并自动装入该角色第 4 槽；营地可以换回或调整其他槽位。每位出战角色始终只有四个技能槽。

| 角色 | 第五技能 | 条件强化一 | 条件强化二 |
| --- | --- | --- | --- |
| 尼布斯 | 三点校射：三段物理，快速增加直感 | 双重确认：满直感时强化单发确认 | 弹道记忆：攻击已标记目标时增强普攻、气息和直感获取 |
| 艾佩莉雅 | 新约切换：低行动消耗的双段魔法 | 六翼展开：高连击、接魔法时增加伊甸段数 | 零时点火：高连击、接物理时降低哨兵行动消耗 |
| 雷克 | 零域归一：主动回到平衡零点并恢复队伍 | 余响庇护：过零后的下一次庇护更强、更便宜 | 清账之符：过零后的下一次咒符变为多段 |
| 哈特 | 心智协同：全队护盾并净化共鸣 | 通路接续：同伴本轮已使用技能，强化安抚治疗与净化 | 护念回响：自身持盾时书页投射变为双段 |
| 潜行 | 灭绝耀光：高魔力投入的三段银焱爆发 | 协同装甲：同伴本轮已使用技能，护甲额外保护全队 | 稳固聚焦：自身持盾时提高聚焦光束的伤害与削韧 |

已获得奖励并满足条件的技能会高亮，显示触发原因；未获得、未满足、未装配分别说明。哈特和潜行的“同伴先行动”条件检查其他出战队员本轮是否使用过技能，要求安排施放顺序。

## 三套战斗场景

雾蚀遗迹供刃卫、司祭与巨人使用；风暴栈桥供雷脊守卫使用；沉星圣所供织者与最终 BOSS 使用。章节地名表达故事中的不同区域，环境资产总数为三套。
