# 3.8：先定场景概念，再制作可玩的模型

这一轮集中更新场景与 BOSS 美术。沿用 3.7 的教学、角色技能、随机三选一奖励与分支远征规则。

## 怎么查看

标题页底部新增「场景与 BOSS 展示」。可以切换五处战场与十名正式 BOSS，查看场景全景、拉近 BOSS，并播放待机、攻击、受击动作。拖动可以旋转 360 度，滚轮缩放。「查看场景概念图」显示这一处场景的生成参考图。

展示不写入角色解锁、BOSS 胜利或远征进度。返回标题后，正常游戏仍按原来的解锁规则进行。

## 场景怎样控制复杂度

先使用内置 imagegen 分别生成五张概念图，再按图中的地形轮廓、主要建筑、配色和材质关系制作 Blender 模型。每处强调一个主要建筑，复用少量阶梯、柱体、栏杆、管道或仪器。保留足够大的平整战斗区，前沿保持低矮，避免挡住人物。

| 场景 | 主要变化 |
| --- | --- |
| 雾蚀遗迹 | 暖石庭院、台阶、悬挂魔晶的破损城门 |
| 雷暴栈桥 | 金属桥板、桥下支撑、引雷塔与粗电缆 |
| 缄页书库 | 象牙色大厅、两侧书架、后方目录铜环 |
| 地下水工厂 | 矩形维修平台、水渠、双闸门、阀轮与泵管 |
| 破碎观星台 | 浅石星图地坪、缺口边缘、浑仪与破损半穹 |

概念图中的密集远方城市、繁茂植被和写实磨损纹理没有逐一建模。游戏采用简化的风格化几何与材质，保留主体构图及辨识特征，不是对概念图的像素级复现。

原始参考图在 `public/concepts/`，完整提示词见 [场景概念图提示词.md](场景概念图提示词.md)。可编辑场景与生成脚本在 `assets_3d/worlds/` 和 `assets_3d/blender/build_worlds.py`。

## BOSS 外形与动画

十名正式 BOSS 使用完整的新 Blender 模型：石晶巨像、镜刃武者、菌伞司祭、四足雷兽、书页蜘蛛、阀门重机、履足炉车、悬浮测绘仪、持剑执行官和六臂环核。三种教学敌人继续沿用各自的小怪造型。

每名正式 BOSS 有三条真正写在 GLB 中的动画片段，共 30 条。待机循环播放，攻击与受击结束后回到待机。战斗中的受击由实际生命损失触发；护盾完全吸收、无伤登记等事件仍有相应特效，但不会让 BOSS 播放扣血受击。

**Blender 做出的模型当然可以播放动画。** 模型是怎样制作的，与动画由谁制作、怎样播放，是分开的事情。可以在 Blender 中建立骨骼和蒙皮，也可以对分件关节直接设置关键帧；导出 GLB 后，游戏引擎播放这些动画。代码负责选择什么时候攻击、什么时候受击，以及配合伤害、镜头和粒子特效。

本轮 BOSS 使用的是 **分件关节关键帧动画**，不是柔性蒙皮角色动画。动作确实由 Blender 导出，但布料、皮肤、面部表情还没有达到完整骨骼角色的制作规格。旧版主要由代码逐帧控制部件角度，旧导出器也关闭了动画导出；那是当时的实现选择，并非 Blender 不能动画。

可编辑原件、全员展示图与动作统计在 `assets_3d/boss-cast/`；生成脚本为 `assets_3d/blender/build_boss_cast.py`。
