# 3.4 本地音效与场景音乐

声音全部通过浏览器 Web Audio 在本地合成，没有连接外部音乐生成服务，也没有新增音频下载。旋律、和声和节奏由程序中的乐谱数据安排；音色由振荡器、滤波噪声、包络与短混响形成。

## 技能与命中

攻击分为枪械、刀剑、奥术、心智、银焱、手术、时钟、水压、熔炉、雷电、孢雾、晶体与法令共 13 个声音主题。每次攻击分别调度起手声和命中声：枪机与低频枪声、刀锋掠风、书页与心智音、银焱电流、器械轻响、齿轮滴答、排水压力等拥有各自的频谱、音高轨迹和衰减。

命中按目标叠加金属、岩石、晶体、软组织、纸张、布料六种材质；重击增加低频和碎屑尾音。多段攻击逐段安排，不把六段声音同时堆在第一帧，段数越多会适当收敛每段增益。重击强调最后一次真正造成伤害的命中。

音画共用 `battle-feedback.js` 的 `impactTiming`，`play(event,{speed})` 同步缩短起手与落点间隔，音高保持不变。真实分段损血来自 `hitDamageFor`：完全被护盾吸收时改为盾面共振；目标已经零生命后的剩余段保留轻微接触声，不再重复肉身重击。准备与结算的招架、回避有各自短音。

## 混音与生命周期

技能总线从 0.88 提高到 1.36，材质冲击层另提高 18%；相较改动前的这套分层实现，起手约增强 1.55 倍、材质命中约 1.82 倍。主音量设置保持原值。音乐鼓组收敛至原包络增益的 65%，并通过独立的动态压缩控制偶发高峰，压缩后再以 0.45 输出增益抵消 Web Audio 压缩器内建的补偿增益；音乐不会占用技能的这一路压缩。混合输出仍经过最终限幅。

配音播放时音乐总线从 0.66 平滑降低到 0.14。静音和切到后台时取消已安排的声音；回来后从当前乐句继续，不补播积压音符。声音同时限制为 192 个声部，过期声源停止后会断开、释放。浏览器恢复音频的异步操作若晚于静音或场景切换，不会重放旧攻击。

胜利、败北都是结束态，状态刷新或静音开关不会重新启动战斗音乐；新战斗或进入营地后才恢复对应乐曲。

## 验证

`tests/audio.test.js` 的 11 项测试覆盖共享时序与二倍速、真实分段损血、盾吸收、十三类攻击和六种材质的实际节点调度差异、十一组音乐的两小节演奏差异、增益归一化、声部上限、配音压低、后台暂停、结束态与异步恢复竞态。

开发页 `qa-audio.html` 使用真实 `OfflineAudioContext` 渲染 33 项：13 种攻击、6 种材质、零血尾段、完整盾吸收、11 组音乐，以及最终音乐和多段攻击的叠加负荷。页面显示峰值、RMS、非零采样数，可逐项试听；不读写存档，也不进入生产构建入口。

最终真实渲染 33 项全部通过，浏览器控制台没有警告或错误。普通攻击峰值约 0.070–0.123，重击材质约 0.122–0.195；音乐 RMS 为 0.00675–0.01263，雷脊与水闸音乐峰值分别为 0.20433、0.21142，其余音乐峰值为 0.03881–0.07959。最高叠加负荷峰值 0.21236、RMS 0.01574，没有削波或非有限采样。

这些结果仅是调度与信号验证，未进行主观听辨，不能代替实际试听中的音色偏好、听感平衡或疲劳感判断。临时开发验证页在测试后清理。

最终混音实测 33 / 33 通过，所有采样有限、非零且无削波。普通攻击峰值约 0.070–0.124，重击材质约 0.123–0.196；音乐 RMS 为 0.00675–0.01263，最高音乐峰值为 0.21142；最终战音乐与六枪、四刀、群体重击叠加时峰值为 0.21236。浏览器无错误或警告。这些是声音信号与运行验证，不代表完成主观听辨。临时验证页在交付前移除。
