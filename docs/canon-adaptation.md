# 本次角色与剧情适配

《停机之前》是为六场战斗新写的设施事故救援支线，不是既有世界观正史。考察队、避难室、供电故障及“归零”停机事故均为本次 demo 情节。人物以项目 `Ric-Others` 中同名原角色卡为依据，未把“学院年”系列提案当作已确认人设。

| 人物 | 原角色卡依据 | 本篇写法 |
| --- | --- | --- |
| 尼布斯拉姆 | `尼布斯拉姆.md`：豪爽、乐天、身经百战的探险家；创立联合工会后又跑去冒险；与雷克交换武器，佩剑作为归途的锚点。 | 他会惦记岔路与新装备，也知道救人时要留路标、分水、护住伤员。好奇心仍在，收尾时主动把探索留到下次。 |
| 艾佩莉雅 | `艾佩莉雅.md`：爱看热闹、嘴欠的格式塔人形；常泡酒吧，尤其爱戳穿雷克的伪装。 | 技术判断用日常语言讲；她揶揄熟人，也会主动留联络器、催担架与饮水，不把关心写成一段宣言。 |
| 雷克老板 | `雷克老板.md`：圆滑古怪的酒吧老板、深渊守门人；知识广博，与尼布斯关系深，有一把对方送的枪。 | 他熟悉路线与危险，但不做百科播报；会打岔，也会突然给出实际提醒。与尼布斯的佩剑联系、开店的习惯自然进入交谈。 |
| 哈特蒙斯 | `哈特蒙斯.md`：博洛伦特纳院长；心灵领域与通路；懒散、傲娇兄控，格朗德是其兄。 | 他先一步下来联系被困学生，嫌应酬麻烦却始终关照他们。心灵联系用于安抚与联络，不被写成包治外伤的神术。尾声保留他对兄长的例外。 |
| 潜行 | `潜行.md`：冷静坚毅、求知欲强的人造探索者，以探索格朗德、建立前哨为任务；银焱模组使用光束，其 AI 是爱看漫画的中二少年。 | 他留在危险栈桥抢修，做判断时说明原因，修好电后仍追查故障。银焱 AI 只由同伴转述一次，潜行本人维持克制，不混成两个说话者。 |

哈特蒙斯与潜行分别在第二、第三战后可编入战斗队伍。对白中的队伍指同行的五人，单场上阵仍为其中三人；未上阵者继续承担联络、设施处理与撤离协助。

## 新版代表对白

| 人物 | 对白 | 所在场合 |
| --- | --- | --- |
| 尼布斯拉姆 | “原因写清楚。别让他们回去还挨冤枉骂。” | 查到设备先烧坏、考察队没有误碰开关后，他惦记的是队员回去会不会受责备。 |
| 艾佩莉雅 | “他没答应。老板你看，他连装都懒得装。” | 雷克要尼布斯别岔出去探险，尼布斯把话题转到绳子上，她当面戳穿。 |
| 雷克老板 | “我来。你那把剑也带好，别又嫌硌，把它塞到包底。回去要靠它认路。” | 留下撤离记号时顺带提醒熟人，原卡中的锚点关系成为实际归路。 |
| 哈特蒙斯 | “我先送人回学院。明天谁都别来找我，让我睡一天。” | 人救出来以后先揽下送医，再给自己拒绝应酬；责任与懒散同时存在。 |
| 潜行 | “下去。我不想自己的前哨也出这种事，得弄清楚它为什么失控。” | 临时电路修好后仍选择同行，有探索和建设前哨的个人动机。 |

心灵联系的对象始终是被困队员：哈特负责保持联系、安抚惊慌和提醒伤员，未直接控制失控构装。设施修复、门锁与核心接口由潜行处理。第二章中队员害怕被怪罪的解释，在第五章由故障记录回应，避免在缺氧救援中突然谈重写报告的插科打诨。

剧情中的六个阻碍有各自的实际作用：入口守卫封路、孢子堵塞进风、栈桥持续带电、巨人堵住避难室、书庭拒绝停机、核心即将切断全区。结局落实到七人获救、伤员送医、核心电源切断与故障记录保留；第三战接好的临时线路继续供电梯撤离。技能数值和资源适配以游戏内角色说明为准。
