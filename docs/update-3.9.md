# 3.9：角色分工、多敌战斗与可行走间章

这一轮把防守进一步放回角色的独特能力里，也把战后流程拆成短交谈、可选操练与实际行走。正式 BOSS 仍为十名，没有用重复增加 BOSS 数量代替玩法调整。

## 角色的防守终于有了不同做法

| 角色 | 调整后的选择 |
| --- | --- |
| 尼布斯 | 掩护射击花 2 AP 和 3 气息，监视选中的敌人；其攻击前先造成 55 物理伤害、削韧 30。击杀或打断可取消出手，否则该次伤害降低 50%。满直感强化截击。这招不再附赠全队护盾。 |
| 艾佩莉雅 | 战术重整保留回复生命与连击，防护改为闪开本轮第一段攻击。后续连击仍会命中，不能把它当成整轮无敌。伊甸集中处理残血目标，哨兵用于攻击敌队。 |
| 雷克 | 正域同调保护并强化自身，负域压低敌人威胁、施加易伤；领域换向只切换方向。平衡仍为 −10 至 +10，每轮向零回复两点。 |
| 哈特 | 心智安抚消耗一条念线，把敌人的一次单体攻击引向另一名敌人；群攻或只剩一个敌人时，该次伤害降低 55%。玩法转为选择值得干扰的预告，锚定与回响承担增幅和进攻。 |
| 潜行 | 脉冲可以低成本打断供能设备，也能驱散强化；普通队友则可直接摧毁设备。护甲保护自己，单体光束与群体耀光按目标数量取舍。 |
| 游木／游墓 | 清创预备受伤后的包扎，治疗发生在承受伤害之后，不能挡住致命伤。切除与创口持续施压，血誓主动献血请船长接管。即时急救和持续缝合继续解决不同时间点的恢复需求。 |
| 补丁 | 收录姿态的充能斩记录目标当前预告，使其本轮最后行动、伤害降低 25%，并取消治疗、召唤、供能或资源抽取等附效；不会跳过核心与终幕规则。 |

这些行动和进攻共用 AP、角色资源与最多五个技能位，没有另设通用招架、回避、迎击或普通防御按钮。护盾仍按批次分别计时两次敌方回合；减伤取最高值，不相加。

魔力循环继续遵守小额多次回魔效率更高、大额兑现效果更强的原则。念线上限四、充能上限三、记录上限十，回魔按一次行动结算，多段和群攻不重复返还。批量准备仍是 2 AP 的纯资源转换。

## 敌人开始互相配合

多敌战斗中，每名敌人有独立生命、韧性、状态与行动预告。可以点击模型或列表选中，或使用 Tab／Shift+Tab 轮换目标。群攻分别命中所有存活敌人，费用和被动回魔只结算一次。主敌倒下后，剩余敌人仍会出手；全部击败才算胜利。

本轮实际使用了三种配合关系：

- **护卫分担。** 巡防小队和缄页织者的护卫可以分担单体伤害。先击破或控制护卫，再集中打主敌；群攻可以绕过这项单体分担。
- **设备供能。** 雷脊守卫带有中继设备，中继哨站由装置、护卫和巡兵组成。打断装置可处理当轮供能，击毁装置会使仍存活的普通敌人停机；特殊核心和终幕不因此跳过。
- **召唤菌簇。** 司祭的播孢会增加场上目标。可以先清理、使用群攻，或用补丁记录附效，避免只对主敌重复单体输出。

同时存活敌人上限三名，召唤单位不是无限增长。新加入的召唤物从下一次敌方回合开始行动，已经倒下的单位不会补打一次攻击。

## 从两招教学，到四招加入正式流程

开局仍是尼布斯独自进入维修道，先用直感发射和整息装填，前三战逐步学习。进入第一名正式 BOSS 前，已招募的人补齐至少四项基础技能；后来招募的角色也从四招起步。

| 角色 | 正式阶段至少掌握的四项基础技能 |
| --- | --- |
| 尼布斯 | 直感发射、整息装填、掩护射击、单发确认 |
| 艾佩莉雅 | 螳螂刀、炼净双枪、战术重整、伊甸之约 |
| 雷克 | 剑式、肉身同调、咒弹、缚足同化 |
| 哈特 | 书页投射、心智安抚、心念锚定、通路回响 |
| 潜行 | 钉刺射击、脉冲射线、钉刺护甲、聚焦光束 |
| 游木／游墓 | 手术刀、清创整备、切除手术、血誓 |
| 补丁 | 钥刃、充能斩、书阵、时光碎屑 |

这些起始组合包含资源循环、进攻与角色特色功能。第五项基础技能可以在一次参战胜利、可选间章操练或个人演练后学会，不要求再连续打几名 BOSS。正式阶段不会退回两招；旧存档中已经学会但顺序改变的技能也保留。

最多装配五项技能。整备增加拖动来源与目标：已装技能互相拖动会交换位置，技能库中的已解锁招式可以拖入技能位；点击装配方式继续可用。奖励中的可选技能仍需获得后才能装配。

## 招募与途中战的安排

每次只在附近一至两名人选中选择，不再弹出六名角色一次任选。

| 时间 | 可以同行的人 |
| --- | --- |
| 第一场入门战后 | 艾佩莉雅／雷克，选择一位先来 |
| 第三场入门战后 | 留在后方的另一位赶到 |
| 刃卫后，清理巡防小队 | 哈特／游木，选择一位先来 |
| 司祭后 | 哈特／游木中的另一位 |
| 雷脊守卫后，清理巡防小队 | 潜行／补丁，选择一位先来 |
| 魔晶巨人后 | 潜行／补丁中的另一位 |

刃卫和雷脊守卫之后分别安排一次巡防小队；织者之后安排中继哨站。两种编队共出现三场，为目标选择、干扰与新技能提供实战机会。一轮远征共十四场战斗：十一场原有主流程，加三场途中战。

途中战和操练只提供技能学习与下一战补给，不新增成长三选一。正式 BOSS 的前七次胜利各发一次成长，三十五项总池中每次随机三项、选一项；读档不重抽。已经招募的旧存档角色不会因新顺序被踢出，后续按仍缺少的人选补齐。

## 战后可以实际走动

正式 BOSS 战后进入一个小型间章。三种布局为回廊、泵站与档案区，每次使用不同装置、目标和短对白。WASD／方向键走动，靠近后按 E 互动；点击目标也能寻路走近。

每处必需内容只有一个主要装置和约四至五句交谈。可选同伴交谈一至两句，操练两句。主要目标完成后，需要走到出口明确互动才会继续。第一处通过联络灯问清伤情，之后分别处理送风、栈桥、阀门、电话、门禁等救援需要，不把教学菜单术语塞进人物台词。

教学每段五至七句，由人物说清动机和互相提醒；玩法规则放在战斗侧栏。正式战前对白继续保持短篇幅，新的步行间章替代旧版较长战后对话。旧档正好保存在旧版战后对白中时，可先完成原段落，不突然切断。

位置、完成目标、当前说话对象与对白位置都会保存。探索交谈可点击空白推进，提供重听、配音开关和状态显示；对话记录只加入实际听过的必需交谈，不提前展示未触发的旧场景。

## 场景与声音

五套 Blender 场景和十名正式 BOSS 的三十条动画继续使用。3.9 增加五张生成环景、平台下方地形以及探索设备和同伴；远处画面用于填充环境，不是可走到的区域。五处场景已逐一截图检查，均完整显示且可旋转 360°。修复了正交相机下的白底，并让水面高饱和矩形边缘渐隐；展示页只展示所选 BOSS，不再夹带战斗附属敌人。

对白库共 **297 句**：复用 198 句，新增或改写 99 句，清理 33 条不再引用的旧音频。全部继续使用既定角色音色，按文本逐句缓存。后续只需重配改过的句子，不必因为增加一个 BOSS 重做整部配音。音乐和技能音效依旧由程序合成，未把音乐提示词当作已生成配乐。

## 保存、验证与当前限制

新远征存档为 v6，战斗存档为 v10。迁移保留旧 v5 的招募、学习、装配与进行中战斗数值；更早的六战和八战远征保留原路线。GM 关闭恢复自然解锁，正在进行的战斗可以完成；教学、编队和召唤单位不进入正式 BOSS 自由挑战。

当前自动检查 **521／521** 通过；公开操作探针 **160／160** 配置找到胜利路径，包括七人独狼十名 BOSS、四技能首关队伍和途中编队战。探针不修改生命、AP 或资源，数据见 [3.9 战斗验证](3.9-combat-verification.json)。它证明打法存在，不等于玩家胜率，也不能单独证明角色已经平衡。

实际浏览器已验证联络灯间章的行走、E 互动、四句交谈、空白推进、位置和对话重载保存，以及出口进入两敌巡防战。在 1280×720 整备界面检查了新加入哈特的四招，实际拖动书页与通路交换位置，重载后保持。单体攻击只伤选中护卫；扩散弹在两敌及三敌战分别对每名敌人造成 54 伤害，只支付一次 2 AP 和 6 气息。掩护射击在巡路残机出手前造成 55 伤害并压低该次攻击，完整敌方回合后确认结余 AP 带到下一轮、达到 8 点。本轮浏览器检查未记录错误。

网页构建与离线打包均通过。独立文件为 **91,334,248 字节／87.10 MiB**，校验内嵌四张原美术图、五张概念图、五张环景、四个 GLB 和 297 句配音，无外部资源依赖。本次只确认离线静态打包结果；本地 file 页面受过浏览器访问策略限制，没有声称直接打开游玩已通过。详细记录见 [验证报告](test-report.md)。

当前行走限于三种小布局，没有开放世界、装备或联网系统。战斗中的前后站位与位移主要是表现，不附带距离增伤规则；BOSS 是可动画的分件模型，尚无完整面部、布料或柔性蒙皮表现。
